## 作品简介

“衣履净界”面向家庭入户场景，将衣物护理、鞋履存换和随身物品处理整合到同一套设备中。作品方案采用模块化结构，结合机械传动、气流循环、视觉感知及语音与触控交互，减少用户在多台设备之间切换的操作。

本仓库提供控制与交互部分的工程文件，供评审查看软件实现和在配套设备上复现。整机结构、硬件电路与演示效果由应用方案、硬件设计文档、实物照片和作品视频配套说明。

## 运行环境

| 模块 | 环境要求 |
| --- | --- |
| STM32 | STM32F407 配套控制板；Keil MDK；工程记录的编译器为 ARMCC 5.06 update 6 (build 750)，器件包为 `Keil.STM32F4xx_DFP.2.12.0` |
| 视觉 | 支持 MaixPy v4、`maix.nn.YOLOv5` 和 `.cvimodel` 的 MaixCAM / MaixCAM-Pro 环境；MaixVision；配套摄像头与显示屏 |
| 串口屏 | 与原工程设备型号匹配的陶晶驰串口屏及兼容的串口屏编辑软件 |

视觉环境按仓库内 `from maix import ...` 接口及 `.mud` / `.cvimodel` 模型格式说明，实际固件版本未随原始文件记录。运行前应核对实物平台，不能直接将此模型作为 K210 的 `.kmodel` 使用。平台说明参见 [MaixPy 官方文档](https://wiki.sipeed.com/maixpy/en/)。

## 当前版本与验证范围

- STM32 两个 Keil 工程引用的文件均已包含在仓库中；编译输出、个人界面配置和备份文件由 `.gitignore` 排除。
- 视觉模型包保留完整的 `.mud` 和 `.cvimodel` 文件。当前模型标签为 `white`，程序在检测到目标时发送 `0x55`，同时在屏幕显示检测框与置信度。
- 当前视觉目录包含一个推理程序；训练数据、训练脚本、原始权重及另一套摄像头程序未随此源码包提供。
- 视觉发送字节与从控当前接收分支的对应关系需要在整机联调时核对，详见[串口与联调说明](docs/RUNNING.md#串口与联调说明)。当前文件不能单独作为全部视觉闭环功能已验证的证据。
- 本次整理完成了工程引用、模型文件和 Python 语法检查。Keil 编译、串口屏编译及硬件运行结果需在配套开发环境与实物上验证。
